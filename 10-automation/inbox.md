# 記録の投函口

日次も週次も、**既存の Issue #1「📥 記録の投函口」へコメントする。** 新しいIssueは作らない。
**標準は手貼り。** claude.ai の GitHub 連携は読み取り専用で Issue にコメントできず、
自前コネクタは未導入（[connector.md](connector.md)）。記録ブロックは自分で貼る。試験官は投稿を試みない。

## 作り方（初回1回だけ）

```bash
gh issue create \
  --title "📥 記録の投函口" \
  --body "試験官が出した記録ブロックを、このIssueへ**コメント**として貼るだけで保存されます。

- このIssueは閉じません。毎日ここに貼り続けます
- \`type: session\` または \`type: weekly\` の行があるコメントだけがWorkflowを起動します
- 保存されると、結果がこのIssueにコメントで返ります
- フォーマットが崩れた場合は原文が \`04-sessions/inbox/\` に残ります"

gh issue pin <番号>
```

## 手貼りの手順（標準）

1. 記録ブロックをコピーする
2. Issue #1 を開く（ホーム画面アイコンか GitHub アプリ）
3. コメントして送る
4. 1〜2分後、「記録しました」が返る

壊れたブロックはコメントを**編集**すれば再実行されます。
