# 記録の投函口 — 貼る手間を最小にする

ChatGPTの無料プランはGitHubへ書き込めません。**手作業として残るのは、記録ブロックを貼る1回だけ**です。
ここではその1回をどこまで軽くできるかをまとめます。

## 方式A: 常設Issueにコメントする（既定・おすすめ）

毎回Issueを作るとタイトルを考える手間が要ります。代わりに、**開きっぱなしのIssueを1つ用意して、そこにコメントを足す**だけにします。

### 作り方（初回1回だけ）

```bash
gh issue create \
  --title "📥 記録の投函口" \
  --body "ChatGPTが出した記録ブロックを、このIssueへ**コメント**として貼るだけで保存されます。

- このIssueは閉じません。毎日ここに貼り続けます
- \`type: session\` の行があるコメントだけがWorkflowを起動します
- 保存されると、結果がこのIssueにコメントで返ります
- フォーマットが崩れた場合は原文が \`04-sessions/inbox/\` に残ります"

gh issue pin <番号>
```

Issue番号が出たら、そのURL（`https://github.com/<OWNER>/<REPO>/issues/1` など）を控えます。

### スマホでの動線

1. **URLをホーム画面に置く**
   Safariでそのページを開く → 共有 → 「ホーム画面に追加」。名前は「記録」など短く。
   Androidなら Chrome のメニューから「ホーム画面に追加」。
   GitHubアプリを開いてリポジトリを探す手間がなくなります
2. 毎日の動作は **アイコンをタップ → コメント欄に貼付 → Comment** の3操作
3. 1〜2分後、同じIssueに「記録しました」のコメントが返ります

タイトルを考える必要も、Issue一覧から探す必要もありません。

> **GitHubアプリとブラウザのどちらでもよい**
> アプリのほうがログイン状態が安定します。アプリで一度そのIssueを開いておくと、
> 通知欄から辿れるので実質2タップになります。

## 方式B: 新しいIssueを立てる（週次レビューなど）

タイトルをあらかじめ埋めたURLをブックマークしておけば、貼るだけで済みます。

```text
https://github.com/<OWNER>/<REPO>/issues/new?title=record
```

週次レビュー用は `?title=weekly` にしておくと後から探しやすくなります。
方式Bで作ったIssueは、保存されると**自動でクローズ**されます。

## 方式C: iOSショートカットで完全に1タップ（上級・任意）

ここまでやると、**ChatGPTでコピー → ショートカットをタップ → 完了**になります。GitHubを開く必要すらありません。
ただし**トークンを1つ発行する必要がある**ので、それが嫌なら方式Aで十分です。

### 準備

1. GitHubで Fine-grained personal access token を作る
   - 対象リポジトリ: このリポジトリだけ
   - 権限: **Issues → Read and write** のみ（Contents権限は不要）
   - 有効期限: 1年（切れたら作り直す。切れても方式Aに戻れるだけなので実害は小さい）
2. iPhoneの「ショートカット」アプリで新規ショートカットを作る

### ショートカットの中身

| # | アクション | 設定 |
|---|---|---|
| 1 | クリップボードを取得 | — |
| 2 | 辞書 | キー `body` に「クリップボード」を入れる |
| 3 | URLの内容を取得 | 下記の通り |

「URLの内容を取得」の設定

- URL: `https://api.github.com/repos/<OWNER>/<REPO>/issues/<投函口の番号>/comments`
- 方法: **POST**
- ヘッダ:
  - `Authorization`: `Bearer <トークン>`
  - `Accept`: `application/vnd.github+json`
- 本文を要求: **JSON**、手順2の辞書を渡す

保存してホーム画面に追加します。名前は「記録を投函」など。

### 使い方

ChatGPTの記録ブロックのコピーボタンを押す → ショートカットをタップ → 終わり。

> **トークンの扱い**
> ショートカットに直接書くとバックアップ経由で他端末へ同期されます。気になる場合は
> 「パスワード」アプリに保存して、ショートカット側から読み出す形にしてください。
> 権限をIssues書き込みだけに絞ってあるので、漏れてもリポジトリのコードは書き換えられません。

## どれを選ぶか

| 方式 | 毎日の操作 | 準備 | トークン |
|---|---|---|---|
| **A: 常設Issueにコメント** | アイコン → 貼付 → Comment | 5分 | 不要 |
| B: 新しいIssue | ブックマーク → 貼付 → Submit | 2分 | 不要 |
| C: iOSショートカット | コピー → タップ | 15分 | 必要 |

**まずAで始めてください。** 3週間続いて、それでも貼るのが面倒だと感じたらCへ移ればよいです。
先にCを作ると、続くかどうか分からない習慣のためにトークン管理が増えます。
