# ChatGPTの定期タスクに登録する文

無料プランの定期タスクは **3個まで・1日1回まで・時刻は「朝」のような枠指定** です。
また、**定期タスクはProjectの指示欄もアップロードしたファイルも読めません。**

そのため定期タスクは **着火（リマインド）だけ**に使い、出題も採点もProjectの中で完結させます。
こうすると、その日の会話が1本にまとまり、記録ブロックまで同じ画面で終わります。

`<OWNER>/<REPO>` は自分のものに置き換えてください。

---

## タスク1: 朝のリマインド（毎日・朝）

名前の例: `Engineering OS 今日の1問`

```text
「Engineering OS の時間です。Project『Engineering OS 試験官』を開いて『今日の1問』と送ってください。」
と一言だけ日本語で伝えてください。

そのあと https://raw.githubusercontent.com/<OWNER>/<REPO>/main/STATUS.md を開いて、
連続実施日数・直近5回の平均スコア・再テスト期限切れの件数の3つだけを1行で添えてください。
読めなければ、その行は省いて構いません。

問題は出さないでください。出題はProject側で行います。
```

> **なぜ出題させないのか**
> 定期タスクは `anchors.md` も出題ルールのファイルも読めないため、ここで出題すると
> 「タスクの会話で出題 → Projectへ問題文を貼り直して採点」という往復が毎日発生します。
> Projectで「今日の1問」と送れば、出題・採点・記録ブロックが1本の会話で終わります。
> **通知はあくまで着火装置**で、届かなかった日はProjectを開けば同じことが起きます。

## タスク2: 週次レビューの通知（日曜・夜）

名前の例: `Engineering OS 週次レビュー`

```text
https://raw.githubusercontent.com/<OWNER>/<REPO>/main/WEEKLY_CONTEXT.md を開いて全文を読み、
今週の数字を5行以内で日本語で要約してください。実施回数、平均スコア、30分内完了率、
Open弱点の数、base_levelの判定だけで十分です。

最後に1行、「Project『Engineering OS 試験官』で『週次レビュー』と送ってください」と書いてください。
```

## タスク3の枠は空けておく

無料プランの上限は3個です。1つは予備として空けておくことを勧めます。
定期タスクを使い切ると、他の用途で作れなくなります。
