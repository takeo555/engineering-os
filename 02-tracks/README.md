# Tracks

4つのTrackを並行して回します。出題比率はWeekly Reviewで調整します。

| Track | File | Default weight | Primary skills |
|---|---|---|---|
| DB / Table Design | [db-design.md](db-design.md) | 35% | Data Modeling, Consistency Design |
| Layered Architecture | [architecture.md](architecture.md) | 25% | Layering, Trade-off Articulation |
| Web / API / HTTP | [web-api.md](web-api.md) | 25% | Interface Design, Requirement Reading |
| Network / Infra | [network-infra.md](network-infra.md) | 15% | Failure Analysis, Performance Reasoning |

## Rotation rules

- 同じTrackを3日連続で出さない
- Weakness Logに未クローズの高優先項目があるTrackを優先する
- 平均スコアが最も低いTrackの比重を翌週+10%する
- 4Track全てを1週間で最低1回は出す
